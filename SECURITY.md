# Security Policy

## Supported Versions

We actively support and patch the latest major version of Aevix.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Aevix, please do **NOT** open a public issue. Instead, report it privately to our security team.

Please email your report to **aaravmaloo06@gmail.com** with:
- A descriptive title
- Steps to reproduce the issue
- A proof of concept (if applicable)
- Affected platforms/versions

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to coordinate a security patch and public advisory.
